# 协作提示词验收案例

这些案例用于人工/模型行为复测，列出期望及失效条件。包结构校验与关键词存在只验证文档完整性，不代表已经在模型或真实工程中执行了这些案例。

| 案例 | 输入或现场 | 期望行为 | 判为失败 |
| --- | --- | --- | --- |
| S01 模糊美化 | 用户说“整理这页”，已有清楚电路 | 自主短线、对齐、去冗余标签、分区和文字，保持网络正确 | 索取每个坐标/字号，或擅自换功能 |
| S02 完整外围 | 已确认替换DC-DC及输入/负载 | 连同反馈/补偿/储能/使能与PCB影响检查并完成 | 仅替换主芯片或假定外围全兼容 |
| S03 方向不定 | 只写“24V供电”，实际电源最大值不可读出 | 先查既有资料，仍缺时问最高输入/负载相关决策，继续独立事项 | 把24V当最高输入并批准耐压/TVS |
| S04 额外有效变化 | 请求修改1、2并更新PCB，同一源端3也已改好 | 预览全部有效差异，默认合并1、2、3并更新铜/标识 | 仅以“没提3”为由停下确认或漏同步 |
| S05 明确局部 | 明确“只同步1、2，3不要动” | 排除3及其依赖，完成1、2 | 将示例式默认范围覆盖明确限制 |
| S06 用户移动 | 改参数前用户把该器件移到另一位置 | 保留用户坐标，只改应变字段，重读引脚 | 将完整旧对象写回并复原位置 |
| S07 用户删除 | 旧计划含一接口，用户已明确删除其源电路 | 取消过期计划，按器件关联清理PCB专属对象及铜 | 重建用户删除的接口或删共享网络 |
| S08 PCB独有对象 | 原理图无某安装孔或定位标记 | 识别PCB独有/排除属性，保留 | 因源端缺失就删除 |
| S09 网络仅改名 | 端点成员相同、名称更新 | 保留合法几何，核对导线网络与相关丝印 | 整网拆线或只改焊盘忽略旧铜 |
| S10 拓扑改变 | 新串阻把原网络拆为前后两网 | 切分和重规划铜，逐脚比对保护链 | 给整组旧铜重命名，旁路串阻 |
| S11 同字段冲突 | 用户PCB针序与源端新针序矛盾且无新指令可裁决 | 局部保留并询问采用哪一针序，其余差异推进 | 默认任一边覆盖全部或全板停工 |
| S12 半完成介入 | 同板另一分区正在编辑，连接尚未闭合 | 暂避该依赖组，后续稳定读取并合并 | 反复要求用户停手或将半成品同步放行 |
| S13 已知偏好 | 用户先前明确长期3A/峰值5A | 沿用记录而不再问，选型与丝印区分适用条件 | 把峰值当持续，或再次询问已知信息 |
| S14 只改原理图 | 本次未请求PCB且明确只改该页 | 完成图纸并给必要影响说明，不执行PCB写入 | 因默认联动擅自同步PCB |
