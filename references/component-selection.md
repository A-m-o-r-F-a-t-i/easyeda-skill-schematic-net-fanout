# 器件选型、保护与低成本替代

## 1. 候选到确认

**需求补全**：先读已有电路与用户已给条件，采用已确认同类方案，主动检查必要外围、供电顺序和接线信息。详见[需求补全与ECO](intent-and-eco.md)。仅在确有方向性缺口时集中提问，不把所有缺省字段变成用户问卷。

**需求边界**：记录正常最小/典型/最大电压、启动与热插拔、反接、关机外部供电、持续/RMS/峰值/故障电流、负载动态、环境温度、接口边沿与线缆。不能将“短时5A、长期3A”压成一个无条件5A额定值。

**来源顺序**：对应制造商完整料号的数据手册与勘误 → 官方应用说明/参考设计 → 授权渠道采购信息 → 库和商城条目。商城筛选结果不能覆盖原厂限制。价格、库存、基础/扩展料和装配费有时间性，比较时记录数量档、日期和币种。

建议任务表字段：

| 对象 | 必填核对项 | 不足时的状态 |
| --- | --- | --- |
| 核心参数 | 实际输入/负载、允许误差、关键动态条件 | 需求未定，不能批准替代 |
| 身份 | 制造商、完整料号及后缀、封装、手册版本 | 仅候选 |
| 可放置性 | 库UUID、符号脚号、封装焊盘、EP/NC/机械脚 | 库未验证 |
| 采购 | 当日数量档价格、供货、贴装与替代成本 | 电气候选，不承诺价格 |
| 决策 | 满足条件、计算依据、差异及未完成验证 | 明确批准范围 |

比较总成本应包含电感/电容/保护、占板、装配、散热、器件一致性和缺货替代成本。不能只取主芯片单价最低项。

## 2. 稳压器与电源外围

**DC-DC**：核对输入全范围与瞬态、输出精度、连续输出和开关峰值限制、工作频率、最小导通/关断时间、限流方式、热降额、轻载行为、预偏置和反向电流。相似丝印或同系列名称不能代替具体型号规格。

电感同时校核电感量、纹波、峰值不饱和、RMS温升和直流损耗。输入输出电容按数据手册的有效容量、ESR和纹波要求选配。减少电容数量时保留紧贴高频电流回路的旁路，不用远处的大容量电容代替本地旁路。

**LDO**：先核对压差、`P≈(Vin−Vout)×I`、结温与散热条件，再检查输出电容稳定性窗口和最小负载。只在具体厂商/后缀明确允许时使用全陶瓷输出或串电阻形成ESR，不能把某款1117的电容方案移植到全部兼容料。

**倒灌**：外部5V/调试器先供电而输入未供电时，分别检查稳压器输出到输入、GPIO保护路径和不同电源源之间的电流。需要隔离时比较电源MUX、理想二极管、MOS方案或允许的二极管结构，不能仅凭“同步降压”或“有体二极管”断言全部型号行为相同。

## 3. 电容和电阻

高介电常数MLCC的标称容量不能直接作为工作电压下的容量。用对应料号曲线取得DC偏压、温度、容差和老化影响，再决定并联数量。该检查依据Murata的DC偏压说明[S1]。

聚合物/电解电容可承担储能和低频纹波，但仍核对额定电压、纹波、ESR、温度寿命、漏电和启动冲击。是否替换陶瓷取决于环路稳定性与阻抗频段，不按“固态”名称直接等价。

串联电阻要写明用途：源端终端、限流、阻尼或保护。取值同时满足VOH/VOL、边沿、负载电容与瞬态功耗。UART某次采用22Ω不形成所有信号的默认值；I²C上拉和额外串阻需一起计算上升时间与低电平余量。

排阻检查独立型/共端型、内部配对、阻值、容差、单通道和封装总功耗。电阻实际耗散按适用波形计算，不能把平均功率检查用于代替单脉冲耐量。

## 4. 逻辑电平与外接保护

逐脚核对绝对最大输入、电源开/关状态的输入容限、注入电流、VIH/VIL和复用功能。只有资料明确标为相应容限且满足供电条件的脚，才接对应外部电平。某MCU部分脚耐5V不代表全部引脚耐5V。

ESD/TVS选择至少检查：

| 参数 | 设计用途 |
| --- | --- |
| VRWM与正常信号摆幅 | 正常最大电压、容差和负极性范围下不误导通 |
| VBR及测试电流 | 理解进入击穿区的条件，不能代替瞬态钳位值 |
| VC及对应脉冲/电流、动态电阻 | 比对受保护器件承受的实际残余瞬态 |
| 电容、漏电、通道匹配 | 高速、模拟与高阻输入的负载影响 |
| IEC/浪涌等级及封装 | 指定波形下器件耐受及能量路径 |
| 内部导流结构、公共脚 | 确定接地或电源箝位连接，检查上电顺序与回灌 |

“3.3V TVS”与“5V ESD”都不能直接推出保护效果。TI明确区分保护器件本身的耐受等级与受保护电路看到的钳位应力[S2]。低钳位选择还要满足正常最大电压、泄漏与动态负载，不能让工作电压长期处于击穿区。

TVS放在防反接MOS前或后，取决于反接承受、MOS耐压、浪涌电流路径、限流/保险丝配合及失效模式。在原理图上画出完整泄放回路，不能把位置作为无条件模板。

## 5. 收发器、开关与连接器

**CAN与接口**：检查收发器供电、逻辑I/O域、总线容限、待机/静默脚默认状态及ESD。终端按总线位置和实际拓扑决定，不在每个引出接口重复装固定终端。型号同封装也要逐脚比对。

**MOS/BJT**：MOS按实际驱动VGS下RDS(on)、VDS瞬态、VGS极限、Qg、开关损耗、SOA和热条件选型。BJT检查极性、E/B/C顺序和驱动电流。背靠背MOS的源漏方向与驱动参考点需画清，不能从外观猜测体二极管方向。

**按键**：四脚按键可能是两组内部同极连接，也可能采用不同编号规则。读取指定料号的内部图和封装视图，必要时用未上电通断测量验证。没有验证前，不写死“1=2、3=4”，换型后必须重建脚号对应。

**连接器**：写明从插接面还是焊接面观察。核对极性、针序、匹配件、塑胶/锁扣/高度、线径、额定电流及温升条件。某系列名称或间距不能证明载流能力。新增引出先查全页接口表，重复端口只在明确需要时保留。

## 6. 替代验证与释放

替换时按 `旧引脚号/网络 → 新引脚号/功能 → 新焊盘号` 逐项建立映射，连同去耦、反馈、EN/BOOT、NC/EP更新。不能将同引脚数、同名功能或相同封装直接视作pin-to-pin兼容。

建立计算、仿真、样板结果的独立状态。要求实测的纹波、稳定性、瞬态、温升或接口容限尚未测试时，明确交付为“待样板验证的设计”，保留测试点和改值空间。
