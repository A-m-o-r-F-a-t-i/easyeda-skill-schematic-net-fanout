# 原理图功能布局与视觉验收

## 1. 先拓扑后框线

建立页间接口表，按电源链、控制链和外设组织页面。同一功能块包含足够读懂该电路的局部器件，避免将芯片、去耦、反馈和接口打散后依赖大量同名标签拼图。电气关联弱的块可以分区，同一局部回路不要为追求块大小一致而拆散。

先放主器件、接口及串并联外围，完成局部连线和属性，再依据全部内容的包围范围绘制分区矩形。包围范围包含符号、引脚外伸、属性、端口文本、分支和注释。模块名称和矩形只表达分类，不参与网络连接。

## 2. 网格与比例

校准当前原理图网格、坐标原点、Y方向和旋转语义。SCH与PCB单位不同，禁止把PCB的mil坐标直接送入原理图。用一个已知符号的相邻引脚距离和截图确认比例。

以当前页网格g为尺度。可从外围件间2～4g、框内边距2～3g、块间3～5g开始试排，随后按引脚和文字实际包围盒调整。这些是排版起点，不是固定验收阈值。

同类无源件对齐中心线或同一功能节点，接口引脚保持顺序。标题、器件参数、设计注释采用少量稳定字号层级。需要增大分区注释时，只改对应文本层级，不将图框、库标题和所有器件文字一起放大。

## 3. 导线与标签

| 场景 | 表达方式 | 检查重点 |
| --- | --- | --- |
| 反馈、滤波、去耦、按键、收发器外围 | 短正交导线 | 读者能直接追踪电流/信号与支路 |
| 一个模块的输入输出、跨页连接 | 明确网络端口 | 名称唯一且上下游方向相容 |
| 主控大量独立引脚 | 按功能组扇出，保留适度间隔 | 标签不压引脚，避免整边交织 |
| 电源和地 | 本地电源/地符号 | 符号连接点真实接线，电源域没有误合并 |
| 有意不连接 | 适当的NC标记或器件明确规则 | 不把未知脚当NC，也不遗漏EP/配置脚 |

连续导线本身已经解释的局部连接不重复挂网络名。必要命名可以存在于底层网表而不全部显示。分区边界不强制每条穿线都加端口。

优先旋转或平移元件消除交叉，再选择上/下走线通道。连接交汇使用明确节点，非连接交叉避免三义性。短线贴到符号外框不代表接到真实引脚端点，必须检查坐标和网表。

## 4. 主控、排阻与保护区

围绕真实引脚分配组织主控四边。UART成对、SPI与中断、I²C、编码器和PWM按功能组显示，同时让排阻通道编号和网络顺序可追踪。不能为了按位号排序打散一对通信信号。

排阻附近放置源侧和接口侧的对应名称，组内实际串联通道连清，避免用一堆相同文本隐藏接错通道。ESD接在真实被保护节点，并清楚画出泄放公共脚。阵列省空间的收益不能抵消跨组绕线和审查困难。

将重要电源范围、持续电流与短时峰值、可选终端、DNP/0Ω配置放在所属电路附近，字数短而完整。大段器件宣传、网页式副标题、无操作意义的小字不放在电路图上。

## 5. 图框、颜色与库内容

功能框有一致边距和标题对齐，但按实际电路复杂度分配面积。留白不足时增大块或拆页，不以持续缩小文字解决拥挤。图框不可压在电阻数值、引脚号、交点和端口文字上。

同页使用少量低干扰颜色，印刷或灰度视图仍可区分信息。用户指定作者/图框颜色时只改指定属性。个人库更新与工程实例更新分别验收，不擅自改变他人库的归属信息。

## 6. 接线说明与介入后的版面维护

每个外接接口提供可追踪的功能/通道名称、针号到网络、供电域与板端信号方向，主从同号接口保留区分。输出给PCB的接口映射用于逐针丝印；不因本地连线禁止重复标签而省略真正有接线价值的接口说明。

用户中途挪动器件或改文字后，以当前有效布局为新的参考，只调整确需避让的部分。保留其内容与风格意图，电路改变后更新关联名称和针序，不能将旧页框、旧坐标或旧属性整体覆盖回来。

## 7. 视觉检查顺序

1. **整页**：主阅读路径、模块排列、页面密度、标题层级和跨页接口是否清楚。
2. **功能块**：主器件与外围朝向、反馈闭环、保护链、连接器针序、接地支路是否可直接理解。
3. **局部放大**：引脚端点、线交点、属性文字、标签锚点、矩形边缘和孤立短线。
4. **保存读回**：确认线段与网表没因对齐、旋转、文字移动发生电气变化。

API没有原生文字包围盒时，保守估算只能筛候选冲突。最终需要截图检查，不能把估计“零相交”写作全部文字可读。
