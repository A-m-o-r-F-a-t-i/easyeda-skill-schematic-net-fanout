# EXPERIMENTAL：大功率、高速与FOC电路审查

**状态：试验性，未完成本环境的专题样板验证。** 本文件是设计输入和审查门，不能将引用参考板的额定能力直接写到新设计上。PCB几何和回流细则由PCB专用Skill的同名试验性专题承载。

## 1. 统一启用与升级条件

用户任务实际涉及对应领域时加载。先建立参数、来源版本、适用拓扑、计算、仿真和待测项。缺少影响安全、器件额定值或采样/时序的参数时，不批准对应电路投产。

每条专题结论使用 `文献规则 / 工程推导 / 已仿真 / 已实测` 之一。升级成熟规则必须给出可复现条件、独立复核及覆盖工作范围的样板结果，不能用“运行过一次”或“DRC为零”替代。

## 2. EXPERIMENTAL：大功率电路

**输入**：正常/最大/瞬态母线，反接和热插拔，持续/RMS/峰值/故障电流，储能、回生、冷却、绝缘边界和测量条件。

**原理图要求**：分别画电源入口与保护、储能、驱动供电、开关功率级、栅极驱动、采样、硬件关断和放电路径。MOS耐压/驱动、连接器、保险丝、分流器与储能电容形成同一故障分析，不能分别按名义值选完就结束。

**审查**：记录电压和电流应力、热预算、启动/关断、回生过压与短路保护动作。原理图明确隔离屏障和测试点，安全距离需按实际工作电压及适用标准确定，禁止套一个通用毫米数。

**试验门**：断电导通/绝缘检查、受控限流供电、驱动失效安全、瞬态与热测试分阶段进行。储能必须可确认放电，未核验的高压/大能量样机不安排无人值守上电。

## 3. EXPERIMENTAL：高速接口

**输入**：协议与代际、驱动边沿、拓扑、线缆/连接器、通道长度、阻抗/时序/损耗预算、器件参考设计和接口规范版本。

**原理图要求**：明确端接、AC耦合、共模电感、ESD、偏置、时钟、复位及电源顺序。器件值和位置应服从具体接口/收发器要求，不能把一个USB或CAN模板用于所有差分线。

**审查**：区分差分对内偏斜、组间时序与绝对长度要求。终端选择需要拓扑依据，不能把全部高速信号都设成同一个阻抗值或等长规则。

**试验门**：仿真输入模型/叠层可信后再评价结果，样板以相应眼图、误码、时序或协议一致性检查确认。只通一次通信不代表通道裕量充足。

## 4. EXPERIMENTAL：电机FOC

**输入**：电机类型与参数、极对数、母线、最大相电流、PWM方式与频率、驱动器、采样拓扑、ADC/定时器资源、位置反馈和控制周期。

**原理图要求**：三相半桥、驱动欠压/故障、默认关断、硬件过流、互补PWM与死区、母线采样、相电流采样、温度与位置反馈完整。逐项核对计时器互补输出、ADC触发和故障输入是否可同时映射到所选引脚。

单电阻母线采样、两/三低边采样和相内采样具有不同的可观测窗口与共模要求。采样增益与偏置以 `Vout=Voffset±I×Rshunt×G` 的全范围检查为起点，并加入器件误差和ADC余量。

采样窗口预算应覆盖驱动延迟、死区/消隐、功率级与放大器/RC建立、ADC采集及触发抖动。窗口不足时调整采样拓扑、PWM/触发或模拟链，不能只降低数字滤波截止频率掩盖原始采样错误。

**试验门**：功率级禁能时校准零点与故障输入，受控低能量条件下确认相序、互补波形、关断、采样窗口和电流极性，再进入空载及逐级负载。禁止通过屏蔽硬件过流保护来验证FOC算法。
