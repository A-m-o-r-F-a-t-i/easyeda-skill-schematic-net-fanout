# 功能块表达示例：主控与外接串口

此文件保留旧示例的引用路径，内容改为通用表达练习。历史ESP32示例的BOM、按键内部脚号和逐脚标签数量不作为可复制电路。实际使用必须填入已验证的器件型号及引脚映射。

## 1. 输入

一个主控串口通过两路独立串阻及ESD接到外部接口，另有复位按键与供电去耦。已知正常逻辑域，但串阻、ESD和按键型号仍需按选型表确认。

## 2. 连接表

| 功能 | 局部连接 | 命名与检查 |
| --- | --- | --- |
| TX | MCU_TX → 独立电阻 → TX_EXT → 接口TX脚 | 电阻两侧必须是不同网，ESD接TX_EXT节点 |
| RX | 接口RX脚 → RX_EXT → 独立电阻 → MCU_RX | MCU输入容限、外设输出和ESD适配 |
| 地 | 接口地、ESD规定参考点、主控地按设计连接 | 检查电源域与屏蔽地关系 |
| 复位 | 复位脚、上拉与按键构成可读局部电路 | 按键内部同极组按具体资料确认 |
| 去耦 | 电源脚、去耦电容、地形成明确支路 | 容量/类型依器件要求 |

## 3. 版面

主控位于块左侧、接口右侧、两路串阻居中平行，ESD置于接口侧信号节点附近。仅在块边界保留主控侧和外部接口名，本地电阻到ESD节点的短线不重复铺满标签。供电支路上置、地符号下置，复位子块与串口之间保留可读间距。

先接线、检查属性，再画分区框。框的范围包括端口文字，标题在独立标题带中。页级截图检查阅读顺序，局部放大检查交点与接线端点。

## 4. 修改与验收

换成另一款按键后，重新读取新引脚并按内部连接重建网络。对比换型前后表中每一项，确认串口两侧网络未被同名标签短接、共享地未被清理、旧按键专属悬空线已删除。保存后读取网表，而非仅确认对象总数。
