# 嘉立创原理图增强 Skill

从 [SKILL.md](SKILL.md) 进入。功能覆盖选型与替代、符号封装核对、局部电路绘制、功能分区、版面美化、保护链路和全差异核对、增量应用的ECO。

## 使用方式

先读取需求补全与ECO规则，再按任务加载 references 中的选型、布局、API/ECO或试验性专题。用户中途有效修改直接进入最新设计，方向性冲突再询问；同板同步默认覆盖全部有效差异并维护接口映射。在线操作由已经授权的EasyEDA接口提供，通用接口知识见 easyeda-api。只使用任务所需权限，不要求全选外部交互权限。

局部连线优先显示电路拓扑，网络端口用于跨区、跨页和主控边界。批量逐脚加标签不再是全部电路的默认表达。

大功率、高速与FOC规则均标为EXPERIMENTAL，未完成该环境的专题样板验证。旧示例路径保留为通用练习，旧BOM及型号特有引脚映射不再作为可复制设计。
